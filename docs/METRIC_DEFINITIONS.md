# Dashboard metric definitions

All calculations use the included synthetic records only.

| Metric | Definition | Operational use |
|---|---|---|
| Active candidates | Records in New, Screen, Hiring Manager Review, Interview, Work Sample, or Offer | See current pipeline workload. |
| Follow-up due | Active or closed records marked as needing a recruiter update or next action | Assign an owner and complete a timely, accurate update. |
| Scheduling gaps | Interview-stage records without a scheduled interview | Coordinate time options and confirm the calendar hold. |
| Possible duplicates | Distinct duplicate groups flagged for human review | Reconcile records before merging; do not infer identity from a name alone. |
| Looks clear | Record has no listed quality issue and no follow-up flag | Indicates only that the sample checks pass, not that the candidate is qualified. |

The dashboard is a practice visualization, not an audited HR report. Its sample values must not be interpreted as business results or hiring performance.
