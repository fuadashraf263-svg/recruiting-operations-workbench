# Sample recruiting workflow

This workflow is a practice example, not an employer's policy and not a record of a real hiring process.

## 1. Confirm a new record

Capture only the information needed to assess and coordinate the application: unique record ID, candidate name, role, current stage, source, responsible owner, last contact date, and next action. Check for an existing record before creating another.

## 2. Review for completeness

Before changing a stage, make sure the required review or feedback is present. Keep missing information visible as a task rather than silently moving the candidate forward.

## 3. Set a clear next action

Every active record should have one owner and one dated next step. If an interview stage has no booked time, identify the interviewer and candidate constraints, then coordinate time options.

## 4. Keep candidate updates moving

When a response is delayed, check the latest confirmed status with the decision owner, then send a concise and truthful update. Do not promise an outcome or date unless it has been confirmed.

## 5. Reconcile possible duplicates carefully

Compare records using authorized information in the actual recruiting system. Confirm that they refer to the same person before merging, preserve useful history, and retain the correct source and audit notes. A dashboard flag is a review prompt, not permission to merge automatically.

## 6. Close the loop

Record the confirmed outcome, send the appropriate candidate message, and follow the employer's retention and deletion rules. Limit access to people who need the information for hiring.

## Weekly review

Review active-stage counts, overdue follow-ups, interview scheduling gaps, missing feedback, and possible duplicates. Assign each issue an owner and next step. Use the counts to locate work, not to make candidate-quality decisions.
